Berpikir komputasional bukan berarti berpikir seperti komputer, melainkan melatih otak manusia untuk merumuskan masalah kompleks dan merancang solusi efisien yang dapat dijalankan oleh manusia maupun mesin.

Tujuan Pembelajaran & Pendekatan Deep Learning

Peserta didik mampu memahami penerapan fondasi berpikir komputasional (dekomposisi, pengenalan pola, abstraksi, algoritma) untuk menghasilkan solusi efisien pada persoalan pencarian, pengurutan, dan struktur data dasar.

🧠

1. Mindful Learning (Berkesadaran)

Sadar akan proses berpikir diri sendiri (*metakognisi*). Kamu tidak sekadar menghafal definisi algoritma, tetapi mengamati setiap langkah logika yang terjadi.

🌍

2. Meaningful Learning (Bermakna)

Menghubungkan konsep abstrak informatika (seperti tumpukan data atau pencarian biner) dengan realitas nyata seperti riwayat *Undo* atau mencari kata di kamus.

🎮

3. Joyful Learning (Menggembirakan)

Belajar melalui eksplorasi simulasi visual interaktif, eksperimen langsung, dan tantangan logika yang memicu rasa ingin tahu tanpa tekanan.

Decomposition

Dekomposisi: Memecah Masalah Kompleks

Dekomposisi adalah kemampuan memecah masalah yang besar, rumit, dan membingungkan menjadi sub-masalah yang lebih kecil, sederhana, dan mudah dikelola secara terpisah.

💡 Contoh Kehidupan Nyata:

Membuat acara Pentas Seni (Pensi) Sekolah terasa mustahil jika dipikirkan sendirian. Dengan dekomposisi, panitia membaginya menjadi divisi kecil: Acara, Konsumsi, Perlengkapan, Keamanan, dan Publikasi.

Pattern Recognition

Pengenalan Pola: Menemukan Keteraturan

Pengenalan Pola adalah proses mengamati kesamaan, tren, atau keteraturan di antara bagian-bagian masalah yang telah dipecah, sehingga kita bisa memprediksi hasil berikutnya.

💡 Contoh Kehidupan Nyata:

Aplikasi cuaca memprediksi hujan berdasarkan pola kelembapan udara dan pergerakan awan. Di e-commerce, sistem merekomendasikan barang berdasarkan pola belanja pengguna sebelumnya.

Abstraction

Abstraksi: Menyaring Informasi Penting

Abstraksi adalah proses fokus hanya pada informasi yang relevan dan penting untuk menyelesaikan masalah, sambil mengabaikan detail-detail yang tidak perlu.

💡 Contoh Kehidupan Nyata:

Peta Rute KRL/TransJakarta hanya menampilkan nama stasiun, jalur warna, dan titik transit. Peta tersebut mengabaikan warna gedung, pohon, atau warung di sekitar jalan karena tidak relevan bagi penumpang.

Algorithmic Thinking

Algoritma: Urutan Langkah Solusi

Algoritma adalah serangkaian instruksi atau langkah-langkah logis yang terurut, jelas, dan terbatas untuk menyelesaikan suatu masalah dari kondisi awal hingga tujuan akhir.

💡 Contoh Kehidupan Nyata:

Resep memasak mie instan atau panduan merakit furnitur. Jika urutan langkahnya tertukar (misal: menuang bumbu sebelum merebus air dibuang), hasilnya tidak akan sesuai harapan.

Panduan Singkat Hosting File Ini di GitHub Pages

Nama File: index.html
1

Buat Repository Baru

Masuk ke akun GitHub.com, klik New Repository, beri nama (misal: informatika-kelas-x), pilih Public, lalu klik Create repository.

2

Unggah File index.html

Klik uploading an existing file, seret file index.html ini ke halaman tersebut, lalu klik tombol hijau Commit changes.

3

Aktifkan GitHub Pages

Buka tab Settings → menu Pages di bilah kiri. Pada bagian Branch, ubah dari None menjadi main (folder /root), lalu klik Save.

4

Bagikan Tautan Web

Tunggu 1–2 menit lalu refresh halaman Settings → Pages. Tautan situsmu (username.github.io/nama-repo) siap dibagikan ke siswa!
